# Full Body Workout Planner

A phone-friendly, offline-first planner based on the Full Body Framework.

## How it works

1. Export workout history from Strong as CSV and save it in Google Drive.
2. Open the planner and choose **Import Strong**.
3. Select the latest CSV using the phone file picker.
4. Choose Kongs gym, home gym, bodyweight or hotel gym.
5. Complete the recovery check.
6. Review the priority areas and select one movement for each of the eight areas.

Strong remains the workout log. The planner does not upload or publish workout data. Parsed history is stored only in the browser that imported it.

The complete Full Body Framework is included as an offline reference page.

## Publish with GitHub Pages

Upload every file in this folder to the root of the Pages repository. In the repository settings, select **Pages**, publish from the chosen branch, and enforce HTTPS.

The site uses relative paths, so it works both at `username.github.io` and at `username.github.io/repository-name/`.

## Updating

Replace the app files in GitHub when the planner changes. Do not add Strong CSV exports to the repository.
